"Three A.M. Review" — a program that writes one one-line joke to `/output/entry.txt`, about working beside an AI coding agent: the agent writes the diff at 3 a.m., the human approves it at 3:01, all the tests pass — and neither of them read a line of it.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (159 characters, deterministic — the same bytes on every run). No network, no input.
